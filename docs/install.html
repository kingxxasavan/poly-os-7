Install guide

Put PolyOS 7 on your computer

About 30 minutes, start to finish. You'll need the PolyOS ISO, a USB drive of 8 GB or more, and (for dual boot) an hour or so beforehand if BitLocker is on.

1

Before you start

  • Back up your files. Installing changes your drives. Copy anything important to another drive or the cloud first.
  • Check your computer. A 64-bit Intel or AMD PC (almost every PC from the last 12 years), or an ARM64 computer with UEFI. 4 GB of memory is enough; 2 GB works in PolyOS's light mode. At least 25 GB of free disk space.
  • Keeping Windows? Plug in your laptop and follow the three steps below.

Turn off BitLocker first (dual boot only)

Many Windows 11 laptops encrypt the drive with BitLocker (also called Device encryption). PolyOS can't be installed next to Windows while it's on: the encrypted partition can't make room, and a new boot menu makes Windows ask for its recovery key. The PolyOS installer tells you when it finds BitLocker.

  1. In Windows, save your recovery key just in case: aka.ms/myrecoverykey.
  2. Open Settings › Privacy & security › Device encryption and turn it off. On Windows Pro, use Control Panel › BitLocker Drive Encryption › Turn off BitLocker, for every drive listed.
  3. Wait until Windows says decryption is complete. It can take an hour or more; keep the laptop plugged in. While it's still decrypting, PolyOS still sees BitLocker.

Turn off Fast Startup (dual boot only)

Control Panel › Power Options › Choose what the power buttons do › Change settings that are currently unavailable, untick Turn on fast startup, then Shut down (not Restart). Otherwise Windows leaves its drive half-closed and it can't be changed safely.

Make space for PolyOS (optional)

PolyOS's Dual boot can shrink Windows by itself. If you'd rather choose the space yourself, do it in Windows: right-click Start › Disk Management › right-click (C:) › Shrink Volume (25 GB or more). Leave the space Unallocated, or make a new drive (D:) from it; you'll pick either one in the installer. Anything on that D: drive is erased when PolyOS goes there.

2

Make the USB drive

Download PolyOS for PC (Intel/AMD) from the download section (ARM64 only for Apple Silicon virtual machines and ARM computers). Everything on the USB drive is erased.

  • balenaEtcher (Windows, Mac, Linux): etcher.balena.io › Flash from file › the PolyOS ISO › your USB drive › Flash.
  • Rufus (Windows): rufus.ie › choose the ISO › Start › when it asks, pick Write in DD Image mode.
3

Start from the USB drive

Plug in the USB drive, restart, and press the boot menu key right as the computer turns on. Pick the USB drive (it may say UEFI: SanDisk or similar).

The PolyOS boot menu appears with a 30-second countdown; Start PolyOS 7 is already selected. PolyOS then runs from the USB drive and doesn't change anything until you install.

The USB drive doesn't start?

  • Reset the firmware to its defaults (in the BIOS: Load Setup Defaults / Restore Defaults, usually F9), save, and try again. This fixes most computers that skip the USB drive. If Windows used BitLocker, it will ask for the recovery key once afterwards.
  • Secure Boot can stay on. PolyOS starts with it.
  • Try another USB port (a USB-A port on the computer itself, not a hub), or write the drive again with the other tool.
4

Install: a whole drive, or next to Windows

PolyOS opens with It's time to get started. First it checks the computer (processor, memory, graphics and the exact model); most computers get everything on, and older ones get a lighter PolyOS. Then:

Install PolyOS 7

A Windows Setup style list of every drive, partition and unallocated space. Pick where PolyOS goes (a partition is erased; unallocated space leaves everything else alone). Delete and New change drives right away, after asking.

Dual boot

Next to Windows. PolyOS finds free space or shrinks Windows, and you choose how much PolyOS gets. Made a D: drive for it? Choose Choose a partition instead (like a D: drive) and pick it in the list.

Try PolyOS first

Look around without installing. Install PolyOS 7 on the desktop and in the dock takes you back to the installer.

Pick an edition (Regular, Developer or Gaming), make your account, choose dark or light, and install. When it's done, PolyOS says Please remove the USB drive now; remove it and restart.

Next to Windows, every start shows the PolyOS boot menu: PolyOS or Windows Boot Manager, starting PolyOS after 10 seconds.

5

After installing

  • Get connected and install drivers. The welcome screens connect to Wi-Fi and open Driver Manager, which finds NVIDIA and AMD graphics, Wi-Fi, touchscreens and pens, webcams and the built-in cameras of newer Intel laptops.
  • Your edition's apps (Gaming or Developer) download the first time you sign in.
  • Updates: Settings › About › Update now installs new PolyOS versions without a new USB drive; Update everything installs Debian's updates. PolyOS tells you when a new version is out.
  • Slower computer? Settings › Power & Performance shows what the hardware check found, switches between Everything on, Smooth and Light, and can limit background activity.
6

If something goes wrong

“BitLocker is on” in the installer
Turn it off in Windows and wait for decryption to finish (steps above), then start the USB drive again.
My drive isn't in the list, or only the USB drive is
Many Intel laptops ship with Intel RST / VMD (RAID) turned on, which hides the drive from Linux. In the BIOS, set the storage mode to AHCI or turn off VMD. Windows needs a small change first so it still starts: search Microsoft's guide “switch from RAID to AHCI” before you change it.
Only “the whole disk” is offered
Use Install PolyOS 7 (the drive list) or, in Dual boot, Choose a partition instead; both list every partition, including a D: drive. The download from before PolyOS 0.7 didn't have this list, so download the newest ISO.
Windows doesn't show in the boot menu
Start PolyOS, open a terminal and run sudo update-grub. If Windows was hibernating (Fast Startup), turn that off in Windows first.
A black screen after choosing PolyOS
Choose Start PolyOS 7 (safe mode) on the USB drive's boot menu, or Advanced options for PolyOS on an installed computer, then install your graphics driver in Driver Manager.
Updating PolyOS 0.7 or older (no Update button yet)
Download polyos-shell_…_all.deb and polyos-desktop_…_all.deb from the newest release, then in a terminal in your Downloads folder: sudo apt install ./polyos-*_all.deb, and sign out and in again. After that, Settings › About updates PolyOS for you.
Still stuck?
Open an issue on GitHub with your computer's model and a photo of the screen. The installer keeps its log at /var/log/polyos-installer.log.
